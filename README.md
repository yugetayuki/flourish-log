# Aubade

朝の行動を10〜20秒で記録し、週次で振り返るための個人用PWA。
依存ゼロの単一HTMLファイルで、記録は端末の `localStorage` にのみ残ります。

**→ https://yugetayuki.github.io/flourish-log/**

## これは何をするアプリか

**行動を起こさせる装置ではなく、計測の装置です。** 行動変容の主役は環境設計（アプリの外）にあり、
このアプリの役割は (a) 未定着の行動が定着するまでの足場、(b) 週次フィードバックループの計測層、
の2つに限定しています。

そのため、意図的に持っていない機能があります。

- **連続日数（ストリーク）を表示しない** — 主指標は週次達成率（例 3/5）。
  完璧主義傾向の強い利用者にとって、ストリークは断絶時の "what-the-hell effect" を誘発しやすいため
- **欠損を失敗として扱わない** — 未入力（中空のドット）と未達（塗りつぶし）を区別する
- **バッジ・紙吹雪・通知・ランキングを持たない** — 反ドーパミン設計
- **残数カウントや督促を出さない** — 事実の提示は可、行動の指示は不可

## 記録するもの

| 時点 | 項目 |
|---|---|
| 昨夜 | 就寝時刻 / アシュワガンダ |
| 今朝 | 眠れた感（計測のみ・目標にしない） / クレアチン / 体重 |
| 昨日 | YouTube視聴時間 / ジム / 勉強 / 任意のカスタム項目 |

タブは 記録 / 週 / 推移 / 週報 / 設定 の5つ。週報タブが出力するテキストを
Claude に貼り付けると、【事実】【解釈】【来週の一点】の形式でレビューが返る運用です。

## プライバシー

- 記録は端末のブラウザ内（`localStorage`）にのみ存在し、どこにも送信されません
- アプリは外部通信のコードを1行も持たず、CSP（`connect-src 'none'` ほか）でも遮断しています
- このリポジトリに実データは一切含まれません

サイト自体は URL を知っていれば誰でも開けますが、開いても中身は空のアプリです。

## 技術

- 単一ファイル（`index.html`）の vanilla JS + インラインCSS + インラインSVG。
  フレームワーク・CDN・ビルド工程なし（オフライン耐性と検証容易性のための選択）
- 保存: `localStorage`、即時書き込み
- ホスティング: GitHub Pages（`main` の `/`）

```bash
npm install
npm test        # vitest 50本 — 実HTMLをJSDOMで起動して操作する
npm run smoke   # 実ブラウザ(Chromium) 14項目 — 描画・保存・CSPの実効性
```

設計判断の背景、不変条件、バックログ、「再訪禁止リスト」は [CLAUDE.md](CLAUDE.md) にまとめてあります。
